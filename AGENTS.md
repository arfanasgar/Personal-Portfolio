
# Project Guidelines

## Portfolio Structure

- Keep all portfolio project metadata in `src/lib/portfolio-data.ts`.
- Use this file as the single source of truth for both the project grid and individual project case-study pages.
- Keep project names, descriptions, technologies, and links consistent across the website.
- Ensure all project descriptions accurately reflect the actual work.
- Do not invent project results, achievements, or external links.

## Code Quality

- Use reusable components wherever practical.
- Maintain consistent naming conventions.
- Keep components modular and easy to maintain.
- Avoid unnecessary dependencies.
- Preserve existing functionality when modifying components.
- Ensure responsive layouts across desktop, tablet, and mobile.

## Design Guidelines

- Use `#1A403C` as the primary brand colour.
- Maintain consistent light and dark themes.
- Prioritise accessibility, readability, and performance.
- Keep animations smooth and lightweight.
